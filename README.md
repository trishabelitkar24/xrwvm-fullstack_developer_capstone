Project Description

This project is part of the IBM Full Stack Software Developer Capstone. It involves developing a full-stack web application for Cars Dealership, a national car retailer in the United States.

The application allows users to explore dealership locations, browse car information, view customer reviews, register and log in, and submit dealership reviews.

Project Objective

To develop a responsive full-stack web application by integrating frontend development, backend services, database operations, REST APIs, and cloud deployment.
